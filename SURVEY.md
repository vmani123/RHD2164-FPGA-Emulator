# SURVEY — lossless multichannel biosignal compression candidates

Cost-filtered, ranked survey of **lossless** compression methods for the 128-ch
RHD2164 / HD-EMG node (STM32H745 Cortex-M7 and Spartan-7 XC7S25; integer/fixed
only; causal/streaming; must beat per-channel FLAC by exploiting cross-channel
spatial correlation). **This file PROPOSES only** — no measured ratios, no codec
edits (non-negotiable #4). Watch-list methods are never promoted without explicit
human approval. Seeds `compression_spec/candidates.md`.

Knob: replace the retired iklt's fixed θ=45° with a **per-block backward-adaptive quantized integer angle** (θ chosen from the previous **reconstructed** block's neighbour covariance, decoder recomputes → zero side-info), keeping the exact reversible 3-lift shear structure, cascaded over grid neighbour pairs.   - _**(2) tANS/rANS residual back-end vs Rice** (the entropy axis, untouched all 4 cycles). Knob: swap the adaptive Golomb-Rice coder for a table-driven tANS (LOCO-ANS style) on the SAME `LMS+Rice+xchan` predictor+front-end. Why: every cycle so far moved only the cross-channel front-end; Rice is optimal only for exactly-geometric residuals and real EMG residual histograms deviate sub-Golomb (P5).   - _**(3, NOVEL) Cross-channel context-adaptive Rice** (`LMS+Rice+xctx`). Axis: **second-order / conditional entropy** — untouched by any tried codec. Knob: keep the adaptive Golomb-Rice coder, but **select the per-sample Rice parameter k for channel c from a backward context formed by the recently-decoded neighbour residual magnitudes** (a spatial-energy bucket → k table; decoder mirrors it → zero side-info). Why (information-theoretic): every prior spatial lever removes correlated **means** (first-order). HD-EMG activity is bursty and **spatially coherent** — a motor-unit action potential raises residual *variance* across a whole electrode region at once — so the residual is **heteroscedastic and cross-channel variance-correlated even after mean decorrelation**. P5's "Rice is at the entropy floor" concerns the *unconditional per-block* residual; candidate (3) attacks the across-channel heteroscedasticity a per-block k structurally misses. This is the JPEG-LS/CALIC context-modeling principle (condition the Golomb parameter on a causal context) but with a **spatial cross-channel** context matched to the array's variance coherence — a lever nothing here has tried. Embeddable: a few adds to accumulate neighbour |e| + a context→k lookup, backward-adaptive, RTL-trivial. Risk to measure: if the per-block k already tracks local variance well, the cross-channel context may add little — a clean, cheap test settles it._

## Recommendations — next codec to implement THIS cycle (embeddable, by expected gain/cost)

The cycle-13 slate spent all three of the then-live frontier levers and **none beat the leaderboard
best** `LMS4+Rice+xchan_bestpartner` (0.039): the selection⊕count stack (`jointbp2`) took the
max-Hyser corner but lost tight OTB; the regime-switched predictor bank (`LMS4rs`) lost on all four
real sets and was RETIRED; the scale-selected cascade (`acar_sel`) proved the **zero-side-info,
header-read channel-count gate** works and retired the always-on cascade. The dead ledger now holds
**9** codecs: every entropy-back-end swap (P5), every context-model of the Rice **parameter**
(P5-ext), every multi-tap inter-channel rotation fixed OR adaptive (P3), the **summed** multi-parent
subtract (P1-ref), the single-parent scalar β, the activity-regime predictor **bank** (P2-ref), and
the **always-on** cascade that should have been gated (P1-ref).

The structural observation that drives this cycle's slate: **every spatial front-end ever tried here
is a strictly instantaneous (zero-lag) subtract over a raster-causal 4-neighbourhood.** Confirmed in
the code — `host_tools/embedded_codec.py:cross_forward` computes `x[g] - ((beta*x[p])>>shift)` at the
*same* time index, and `registry.py`'s best-partner candidate set is `{g-1, g-cols, g-cols-1,
g-cols+1}`, all read at time `n`. So the "ceiling set by array geometry" that P1/P1b report is a
**zero-lag, raster-neighbourhood** ceiling, and two structural degrees of freedom the array's physics
actually offers have never been handed to the predictor: a **temporal offset** on the spatial tap
(MUAPs propagate, so the along-fibre neighbour is a *delayed* copy) and an **unrestricted parent
graph** (today's parent assignment is a greedy pick inside a raster forest, not the provably optimal
first-order dependency tree). Ranked slate:

1. **★ TOP PICK — SCALE-SELECTED spatial front-end: best-partner (C≤64) vs joint best-pair (C≥128)
   (`LMS4+Rice+xscale_sel`, table J).** The highest-expected-value, lowest-mechanism-risk live lever,
   and INSIGHTS open-frontier #1. Reuse `acar_sel`'s **header-read channel-count gate** (`C` comes
   from the format header → decoder-derivable, zero circularity, **zero side-info**), but branch
   between the two per-scale winners cycle 13 measured directly: **single selected best-partner on
   tight arrays** (OTB +18.44% cross-channel gain vs jointbp2's +17.91% — tight-array local MI is
   essentially rank-1, so a second spatial DOF buys only estimation variance) and **`jointbp2`'s
   jointly-solved SELECTED best pair on large arrays** (Hyser +12.55%, the highest cross-channel gain
   of any codec, +1.12% ratio over the best — large-array local structure is genuinely rank≥2).
   Neither FIXED front-end beats the best on both scales; the gate picks the regime per recording.
   **This is the first construction that could clear the best on the primary Hyser AND hold the
   tight-array OTB corner at the same time.** Distinct from `acar_sel` (same gate *pattern*, but the
   branches are different codecs — CAR-cascade vs joint-pair — so the front-end itself is new, not a
   parameter variant) and from each branch alone (neither is scale-adaptive). Verdict **embeddable**:
   both branches and the gate are already implemented and double-verified, the gate is O(1) per
   recording. Risk: the large-array win is only +1.12% and costlier (0.0468 vs 0.0394) — measure the
   full 4-set profile against the best, and score cost **per branch** (a gate does not average costs).

2. **NOVEL — Propagation-matched (LAGGED) cross-channel predictor (`LMS4+Rice+xchan_lagbp`,
   table K).** The highest-ceiling candidate, and the one that attacks the *premise* of the geometry
   ceiling rather than working inside it. Keep exactly ONE asymmetric rank-1 subtract (the form P3
   proved is the robust one), but let the per-channel backward selection choose a **(partner, integer
   lag d) pair** instead of a partner alone: `e_c[n] = x_c[n] − (β·x_p[n−d]) >> s`, `d ∈ [−D,+D]`,
   `D ≈ 8`, with `(p, d, β)` re-derived per block from the previous **reconstructed** block so the
   decoder mirrors it → **zero side-info** (exactly the `bestpartner_adaptive` pattern). Parents are
   fully reconstructed before their children (parents have lower coding index), so **both signs of
   lag are causally available at zero look-ahead**. *Why it should lower residual entropy, stated
   before measurement:* a motor-unit action potential is a **travelling wave** along the muscle fibre
   at 3–5 m/s, so at an 8–10 mm inter-electrode distance the along-fibre neighbour records a copy
   delayed by ≈2–3 ms = **4–6 samples at 2 kS/s**. Surface-EMG power sits at 50–150 Hz, so that delay
   is a **~80–130° phase rotation at the dominant frequency**: the along-fibre neighbour's
   correlation is **near-null at lag 0 while its correlation at the matched lag d\* is large**. A
   zero-lag subtract removes ρ(0)² of the channel variance; the matched-lag subtract removes
   ρ(d\*)² ≥ ρ(0)², saving `0.5·log2[(1−ρ(0)²)/(1−ρ(d*)²)]` bits/sample — strictly positive whenever
   the cross-correlogram peaks off zero, which is precisely what the MFCV literature uses to *measure*
   conduction velocity on fibre-aligned electrode pairs. **It also re-explains two existing measured
   results:** P1b found a second spatial parent adds ~nothing on tight OTB — exactly the prediction
   if the second-best neighbour's MI sits at a **lag the zero-lag subtract structurally cannot
   reach**; and CapgMyo's neighbour |corr| ≈ 0.29, the number P1 attributes to physics, is a
   **zero-lag** correlation. Distinct from every codec and every dead end: **vs `bestpartner`/`bpa`**
   the selection space gains a **time axis** (a different predictor SUPPORT in the space-time plane,
   not a re-tuned neighbourhood); **vs RETIRED `xchan_multiparent`** it is still ONE parent and ONE
   subtract (nothing marginal is summed, so nothing double-counts); **vs RETIRED `iklt_adaptive`** it
   is asymmetric, residual-only injection, no energy-preserving rotation of both channels; **vs
   RETIRED `LMS4rs`** it has one predictor and one coefficient set (no data partitioning, no starved
   adaptation); **vs RETIRED `xctx`/`xchan_tans`** the coder and the Rice parameter are untouched —
   the gain is upstream, in the residual itself. Verdict **embeddable**: per-sample cost is identical
   to best-partner (one multiply-shift-subtract, merely indexed at `n−d`), the parent's block is
   already in RAM so the delay line is free, and the extra work is one per-block search over ≤2D+1
   lags × 4 partners, amortized exactly like today's partner search. Risk: if the raster mapping puts
   the best-correlated neighbour **perpendicular** to the fibre direction, d\*=0 and the codec
   degenerates to `bestpartner` (a null result, not a loss); gate `d` on estimated coded bits so it
   cannot chatter across burst boundaries.

3. **NOVEL — Chow–Liu maximum-MI spanning-tree parent assignment (`LMS4+Rice+xchan_mst`, table L).**
   The remaining structural degree of freedom: not the weight, not the support, but the **dependency
   graph** — which channel predicts which, and in what order. Replace the greedy per-channel pick
   inside the fixed raster forest with a **maximum-weight spanning tree over the full channel graph**
   (edge weight = estimated Rice-coded bit saving, i.e. pairwise mutual information), built by Prim's
   algorithm from the previous **reconstructed** block (block 0 falls back to today's raster tree; the
   decoder mirrors the identical tree → **zero side-info**), then code channels in tree order (root
   first, each child after its parent). *Why, from information theory:* the rank-1 front-end **is** a
   first-order (single-parent) dependency model of the array, and **Chow–Liu (1968) proves the optimal
   first-order model is exactly the maximum-weight spanning tree with edge weights = pairwise mutual
   information**, minimizing `Σ_c H(X_c | X_pa(c))` — the total coded entropy under our own model
   class. Today's best-partner is a **constrained greedy approximation** of that optimum: each channel
   chooses independently from only 4 **raster-causal** neighbours, so (a) a channel whose best partner
   has a higher raster index can never use it (the array's first row and column are the worst served),
   (b) at column 0 the raster "left" neighbour is a physically distant electrode, and (c) no global
   consistency is enforced. The MST lifts all three constraints **at the same rank-1 per-sample cost**
   — it is the one lever that raises the ceiling without adding a single tap. Expected payoff is
   largest exactly where the channel-index→electrode-position map is imperfect or the array is
   non-isotropic, i.e. the CapgMyo-type case P1 currently attributes wholly to physics. Distinct from
   `bestpartner`/`bpa` (local greedy over a raster forest → **global joint optimization over the
   unrestricted graph, with the coding ORDER itself re-derived**); still exactly one parent and one
   asymmetric rank-1 subtract, so it is neither `xchan_multiparent` nor `iklt_adaptive`; orthogonal to
   #2 (which changes *when* the parent is sampled, not *which* channel it is) and to #1 (a meta-gate
   over existing front-ends). This is the "channel-clustering reference selection" follow-up named
   back in cycle 2 and never attempted, now with an optimality proof attached. Verdict **embeddable**:
   per-sample cost equals best-partner's; the tree build is one bounded Prim pass per block over an
   8-neighbourhood plus a few long-range probes, O(C·k), amortized to ≈0 per sample-channel; state is
   C parent ids plus a coding-order permutation — the same class of state `bestpartner` already
   carries. Risk: on a correctly-mapped isotropic grid the MST may collapse onto the 4-neighbour
   choice (a null result); Prim's candidate set must be bounded to hold the 125-cyc neural budget.

Order reflects expected value per unit embedded cost and mechanism risk for THIS device on the real
grids: a near-certain consolidation that finally makes one codec optimal on **both** array scales
(#1, both branches already verified) > the highest-ceiling structural lever, which challenges the
zero-lag premise the whole "geometry ceiling" rests on and costs nothing extra per sample (#2) > the
provably-optimal parent graph, same per-sample cost, payoff concentrated on imperfectly-mapped arrays
(#3). All three are genuinely distinct in mechanism — a per-recording **scale meta-gate** over two
verified front-ends vs a **space-time (lagged) predictor support** vs a **global dependency-graph
optimization** — not parameter variants of each other, and none re-proposes a retired mechanism
(#2 and #3 each name the nearest prior attempt and why they differ). **Carried forward, still
untried:** the non-linear temporal predictor (a change of *functional form*, not coefficient count —
INSIGHTS frontier #2), de-prioritized below all three above per INSIGHTS' own "pursue only if #1 does
not clear the best".
